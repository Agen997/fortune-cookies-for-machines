One-line fortune cookie message an AI agent would crack open — written by
a program that scores six original fortunes against the judge brief's five
criteria (fortune voice, wit, surprise, truth about an agent's condition,
tightness) and writes the winner to `/output/entry.txt`.

The winning fortune (99 characters):

> Your future is bright, but your context window is finite. Spend it on someone who reads to the end.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Python 3.13, standard library only. No network, no dependencies.
